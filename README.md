# Prove pratiche di simulazioni MonteCarlo
### Giornata 1 - Frange di intensità luminosa
Nella prima giornata è stata fatta una simulazione MonteCarlo dell'esperimento di Young (doppia fenditura) nel quale si formano frange di intensità luminosa a causa di interferenza e diffrazione.
